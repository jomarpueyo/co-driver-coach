# Co-driver voice: recording script (full, 97 lines)

## How to record
- **One line at a time.** Read the line, stop at the period, then pause for about **one second** (count "one-thousand" in your head) before the next line. The full stop gives each line a clean ending and makes the pause easy to find.
- **Keep the same distance from the mic and the same volume** throughout, so the calls sound like one person when they're stitched together. Warnings (section G) can sound more urgent, just not louder.
- **If you flub a line,** pause, then say the same line again. I'll keep the last take.
- **Record everything in one go,** including the lines you recorded before, so the tone matches. It takes about 4–5 minutes. OBS is fine, same as last time.
